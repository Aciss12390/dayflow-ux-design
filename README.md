# DayFlow - UX/UI Design Project

DayFlow is a mobile application concept created to help users organize their day, manage tasks, track habits, and review daily progress.

The project was designed in Figma as part of a UX/UI assignment. It focuses on simplicity, readability, visual consistency, and a clear user flow.

## Application purpose

DayFlow is intended for students and working people who want to organize their daily responsibilities in a simple way. The application allows users to view their daily plan, add a new task, track habits, and check a summary of the day.

## Main features

* Displaying a daily task list
* Marking tasks as completed
* Tracking daily habits
* Adding a new task through a simple form
* Showing daily progress and summary

## User flow

1. The user opens the application and sees the start screen.
2. The user clicks “Zacznij planować” and goes to the dashboard.
3. On the dashboard, the user sees today’s tasks, habits, and progress.
4. The user clicks the plus button to add a new task.
5. The user fills in the task name, category, priority, and deadline.
6. After saving the task, the user returns to the dashboard.
7. At the end of the day, the user can open the summary screen.

## UX principles used

The design uses selected UX heuristics and psychological laws, including:

* Visibility of system status
* Consistency and standards
* Error prevention
* Recognition rather than recall
* Hick’s Law
* Fitts’s Law
* Goal-gradient effect
* Zeigarnik effect
